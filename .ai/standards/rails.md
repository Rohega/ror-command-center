# Rails stack

Applies when `_stack_id` is `rails`: a `Gemfile`, `config/application.rb`, or `bin/rails`. Those markers win over `next.config.js`, `next.config.mjs`, and `next.config.ts`.

The workflow is `new-feature`. `next-feature` is not this stack.

Membership is the list `.ai/stacks/rails/STANDARDS`. The markdown stays in `.ai/standards/`. Python and a standalone React app are not stacks.
