# Next.js stack

Applies when `_stack_id` is `nextjs` (`next.config.js`, `next.config.mjs`, or `next.config.ts`, and no Rails marker).

The implementer is `frontend-react-inertia-developer`. Do not add a second specialist for this stack. Python and standalone React are not stacks.

The workflow is `next-feature`. `new-feature` stays the Rails workflow.
